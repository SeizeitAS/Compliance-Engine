# Internationalisation

- **Rule:** code, comments, identifiers, commit messages and documentation are English. Only files in `locales/` contain other languages.
- **API:** `src/i18n/index.ts`: `loadCatalogs(dir)`, `createTranslator({locale, catalogs})`, `negotiateLocale(requested, supported)`.
- **Keys:** dotted, stable, lower-case segments (`screening.passed`). Error reasons from code are enum values mapped to `errors.<area>.<REASON>`, so library code never contains display text.
- **Plurals:** `key.one` / `key.other` via `Intl.PluralRules`; pass `{count}`.
- **Fallback:** `nb-NO` -> `nb` -> `en` -> the key. Aliases `no` and `nn` resolve to `nb`.
- **Adding a language:** see `locales/README.md`. The test suite checks keys and placeholders.
- **Not covered yet:** number/date/currency formatting (use `Intl` with the translator's locale), right-to-left layout, and translating the Markdown documentation (English is canonical).

```ts
const tr = createTranslator({ locale: "nb-NO", catalogs: loadCatalogs("locales") });
tr.t("screening.passed", { version: 3 });
```
