# Contributing

1. **English only** for code, comments, commit messages, issues and documentation. User-facing text goes in `locales/`.
2. Pick an item from `docs/SCRUM.md` or add one before starting.
3. Requirements: Node 22.18 or newer. Run `npm test` before every push. No runtime dependencies without discussion.
4. Log your hours in `docs/time/timelog.csv` (`docs/TIME_TRACKING.md`).
5. Keep the TypeScript reference implementation and the Compact circuit in agreement; change both or neither.
6. Never commit secrets, personal data, real sanctions-list subjects or customer data.
7. Follow the Definition of Done in `docs/SCRUM.md`.
